# Cerere de mostră pentru evaluare — draft, netrimis

Poate fi trimisă prin [contactul oficial Catfish](https://anatomy3datlas.com/contact/).
Este o cerere de licențiere a asset-urilor, nu de abonament la aplicație.

## Subject

Request for an authorized 3D sample and web-application asset licensing terms

## Message

Hello Catfish Animation Studio team,

We are developing a bilingual Romanian/English educational 3D anatomy atlas
using Three.js in a web browser. Before purchasing an asset license, we would
like to evaluate the quality and technical compatibility of your models.

Could you provide one representative bone model, preferably a skull bone, in
GLB/glTF, FBX or OBJ format, with its materials/textures and a written temporary
evaluation license? We would start with one bone; a representative muscle and
nerve sample would be useful later if available.

The initial evaluation would run privately on localhost in an isolated working
copy. We would not extract resources from your installed application, publish
your files, commit them to our public GitHub repository, or deploy them without
your explicit permission and the appropriate license.

Please confirm:

- The rights holder and which exact files/subassets the evaluation covers.
- Whether private browser rendering, format conversion, material adjustment,
  anatomical registration and internal comparison screenshots are permitted.
- Evaluation duration, deletion/expiry requirements and attribution conditions.
- Units, axes, rest pose, stable anatomical identifiers, separate selectable
  parts, anatomical review status, model counts and available LODs/textures.
- Pricing and terms for eventual public web-app embedding, including browser
  delivery of model data, adaptations, commercial use and any required asset
  protection. Raw model redistribution through a public repository would remain
  excluded unless separately authorized.
- Whether skeletal, muscular and nervous models share a consistent coordinate
  frame, and the documented completeness and limitations of each system.

If you do not offer downloadable licensed assets, please let us know whether an
official SDK, embedding arrangement or another authorized evaluation is available.

Thank you.
