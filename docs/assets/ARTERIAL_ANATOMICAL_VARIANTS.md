# Arterial variation contract

Geometry, relationship graph and evidence must agree for a displayed variant.
`ArterialEdge.variant` and `ARTERIAL_VARIANTS` retain the existing source-specific
right-coronary posterior interventricular branch. This does not prove complete
dominance territories and is not toggled into left/codominance by changing color.

No alternate arch branching, Circle of Willis, accessory renal, hepatic,
mesenteric, hand or distal limb geometry is currently integrated. Missing variants
are acquisition targets, not combined into a fictitious universal reference.
Male testicular geometry is explicitly sex-specific; no female pelvic source is
merged into this reference. Female anatomy remains a separate missing target.

Future acceptance requires: stable variant ID, cited source/version, affected
canonical structures, specimen applicability, compatible reference frame, actual
geometry and its alternate edge set, measured registration and reviewer decision.
Text-only candidates must remain text-only until these gates pass.
