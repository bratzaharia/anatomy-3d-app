# Arterial registry and actual coverage

**PARTIAL**, not a complete human arterial inventory. The filename describes the
long-term objective, not a present medical-completeness claim.

There are 219 source-mapped selectable records: **214 individual identities and
5 source sets**. Of these, 212 records are newly imported and 7 reuse the cardiac
module. The five sets are posterior intercostal arteries, oesophageal aortic
branches, bilateral AICA, segmental pulmonary arteries and subsegmental pulmonary
arteries. A set is not counted as individually segmented constituent vessels.

New source ownership: 362 OBJ files, plus one recorded duplicate alias excluded
from rendering. The existing seven cardiac arteries use 20 source files. The
machine-readable matrix is [arterial-coverage.json](arterial-coverage.json),
regenerated by `pnpm arterial:coverage --write`; the pinned geometry manifest is
`packages/anatomy-data/src/arterial-manifest.json`.

The registry also declares **23 missing target families**, including external
carotid/facial branches, additional cerebral segments, coronary detail, pelvic
branches, deep femoral/fibular arteries, spinal vessels, female pelvic reference
and perfusion maps. Each family can contain many named vessels. Therefore
219/(219+23) is **not** a valid percentage of human arterial completeness. A
defensible complete-vessel denominator still needs anatomical/editorial review.
All 219 available records have geometry and interaction; zero have qualified
medical approval. Registry names alone do not increase geometric coverage.

Publisher FMA IDs are retained, not fabricated TA2 identifiers. RO terminology
is editorial, pending review. Existing cardiac Latin terms remain provisional;
new vessels do not get invented Latin labels. Source IDs and both languages are
searchable. Missing Latin is visibly disclosed.
