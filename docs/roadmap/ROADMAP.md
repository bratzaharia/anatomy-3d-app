# Roadmap

## Milestone 1 — interaction foundation

Domain contracts, catalogs, composable filters, fixture renderer, camera views, hover/selection, inspector groups, RO/EN localization, responsive layout, validators, tests, CI, and provenance policy.

## Milestone 2 — sourced skeletal view

Implemented: BodyParts3D source/license audit, reproducible bone-subset import, lossless GLB compression, 29 semantic mappings from 202 source meshes, actual bounds for focus/fit, loading/retry, and browser checks. Remaining: qualified medical/translation review, physical-device performance and context-restoration measurement, and approved models for other systems.

## Milestone 3 — regional detail

Pilot one high-value region with verified structures and content, explicit LOD, hierarchy breadcrumbs, group completeness, and expert review. Expand only after pipeline and performance targets hold.

## Future native evaluation

Keep core/data packages platform neutral. Benchmark React Native + Expo with R3F/native against a platform-native renderer; share stable IDs, catalogs, translations, filters, hierarchy, and compatible compressed assets, not DOM UI. Define per-platform memory budgets, touch behavior, and offline asset packs. A PWA is not the native-app plan.
