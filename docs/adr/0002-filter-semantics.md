# ADR 0002: derived All and empty selection

Status: accepted, 2026-10-27.

“All” is derived: it is checked exactly when every currently available category is selected. Clicking checked “All” clears every category; clicking unchecked “All” selects every available category. Clearing all is an intentional empty scene. Planned systems are visible but disabled and do not participate in “All.” Local hide applies after systems; isolate restricts the system-visible set. The central resolver is the only source of geometry visibility.
