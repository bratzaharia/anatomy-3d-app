# ADR 0001: renderer boundary and honest fixture

Status: accepted, 2026-10-27.

No medically verified, redistribution-cleared model was supplied with the workspace. Shipping an unverified external download or implying primitive geometry was anatomy would violate the product requirements. The first milestone therefore uses a prominently labeled original abstract fixture behind a renderer boundary. Stable anatomy IDs, visibility, groups, localization, and selection remain independent of Three.js. The fixture must be removed when an audited model is integrated; its geometry is never a medical-content source.
