# ADR 0003: future native clients

Status: accepted, 2026-10-27.

Native applications are deferred. Renderer-independent core and data packages can be consumed by web and future mobile clients. DOM components and WebGL renderer code remain web-owned. A later benchmark will compare Expo/React Native with R3F/native against native rendering, using platform memory budgets, touch requirements, offline packs, and compressed-format support as decision inputs.
