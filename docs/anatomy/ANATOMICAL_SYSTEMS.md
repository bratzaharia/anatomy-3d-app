# Anatomical systems

The registry includes skeletal, muscular, nervous, arterial, venous, lymphatic, respiratory, digestive, endocrine, urinary, reproductive, and integumentary systems. Only skeletal currently has sourced geometry and is selectable. The abstract fixtures for other systems have been removed; their registry entries remain visibly planned.

The filter engine accepts any combination and never treats categories as mutually exclusive. Composite views are presets over system IDs, not duplicated structures. Future categories such as ligaments, tendons, fascia, cartilage, connective tissue, adipose tissue, and serous membranes should be modeled as explicit registries or structure types based on the use case—not overloaded into a biological system.
