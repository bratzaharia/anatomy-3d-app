# Anatomy feature workflow

Inspect current schemas, catalogs, system/region registries, translations, and manifests. Establish terminology and relationships from a cited source; do not invent content. Add stable IDs, RO/EN names, provenance, hierarchy/group references, and asset mappings. Integrate visibility through the central resolver and interaction through canonical IDs—never display names.

Add domain tests, localized component coverage where relevant, manifest/translation validation, and measured performance notes for new geometry. Run typecheck, targeted tests, validators, and build. Report structures added, source and review status, asset/license evidence, UI behavior, checks run, and remaining medical-review work.
